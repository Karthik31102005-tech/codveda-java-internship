
# Codveda Java Development Internship

Java development projects completed for the Codveda Technology internship.

## Level 1 — Basic
1. Basic Calculator
2. Factorial Calculation using Recursion

## Level 2 — Intermediate
1. Employee Management System using ArrayList
2. Simple Banking Application

## Level 3 — Advanced
1. Multithreaded Chat Application using Java Sockets and Threads
2. Binary Search Tree with Insertion, Deletion, Search, and Traversals

## Technologies
- Java 8
- Object-Oriented Programming
- Collections Framework
- Multithreading
- Java Sockets
- Data Structures and Algorithms

## How to Run
Open a terminal in the respective level folder, compile the required Java file using `javac`, and run the program using `java`.

For the chat application, compile both `ChatServer.java` and `ChatClient.java`, start the server first, and launch clients in separate terminals.
